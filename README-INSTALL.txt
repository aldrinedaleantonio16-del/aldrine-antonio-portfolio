This is a self-contained portfolio. The HTML includes its CSS, JavaScript, icons, and original SVG illustration, so no assets folder is needed.

UPLOAD STEPS
1. In InfinityFree File Manager, open the document root for aldrine-antonio.infinityfree.me (usually that website's htdocs folder).
2. Upload index.html and index.php directly into that folder. Do not upload the ZIP itself as the website homepage.
3. If index.html or index.php already exists, replace it with the matching file from this ZIP.
4. Open https://aldrine-antonio.infinityfree.me/ and press Ctrl+F5.
5. If you still see 404, the files are in a different folder than the domain's document root. Check the path shown in File Manager.

Both index.html and index.php contain the same complete self-contained website. The illustration is embedded inline in the HTML. The contact form is a demo and does not send email.
